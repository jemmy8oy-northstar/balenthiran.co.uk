# Instructions for Antigravity AI

These instructions are tailored for Antigravity AI to ensure consistency and quality while working on the balenthiran.co.uk project.

## Project Context
- **Owner**: James Balenthiran
- **Scope**: Personal portfolio website.
- **Tech Stack**: React (Vite), TypeScript, Vanilla CSS.

## Coding Standards
- **Component Structure**: Keep components small, reusable, and focused.
- **Styling**: Prioritize Vanilla CSS with a focus on premium aesthetics (gradients, micro-animations, glassmorphism). Avoid utility-heavy frameworks unless specifically requested.
- **Documentation**: Keep the `README.md` and `docs/` folder up to date with all major changes and decisions.

## Design Aesthetic
- **WOW Factor**: Designs should be modern, clean, and "premium".
- **Interactivity**: Use subtle hover effects and transitions to make the site feel alive.
- **Responsive**: Ensure all UI elements work perfectly on mobile and desktop.

## Workflow Rules
- **Task Tracking**: Always update `task.md` before starting a new phase.
- **Planning**: Create/update `implementation_plan.md` for any non-trivial architectural changes.
- **Verification**: Summarize work in `walkthrough.md` with proof of testing (code snippets/explanation). **Do not use the browser tool for verification** unless explicitly requested.
- **Strictly No Browser**: Avoid `browser_subagent` or `read_browser_page` tools.
